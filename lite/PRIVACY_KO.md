# sCollectPlay 및 sCollectPlay Lite 개인정보 처리방침

기준일: 2026-10-23

## 요약

sCollectPlay와 sCollectPlay Lite는 개인정보를 **전혀** 수집하지 않고, 저장하지 않으며,
전송하지 않습니다. 이 앱들은 오직 사용자의 Mac 또는 Windows PC에서만 동작합니다. 계정도, 클라우드
연결도, 분석 서비스도, 광고도 없습니다.

## 앱이 처리하는 데이터

앱은 사용자가 명시적으로 건네준 폴더 안의 미디어 파일을 읽습니다. 건네주는 방법은
열기 대화상자에서의 선택이며, 스캔할 폴더, iTunes 또는 Apple Music XML, sCollect
라이브러리 가운데 하나입니다. 읽는 것은 파일 이름, 파일 크기, 날짜, 그리고 파일의
메타데이터이고, XML이나 라이브러리라면 그 카탈로그 정보도 함께 읽습니다.

선택하지 않는 한 앱은 어떤 파일에도 접근하지 않습니다. macOS가 앱 샌드박스를 통해
이를 강제합니다.

## 앱이 Mac에 남기는 것

- **설정과 창 위치** — 앱의 보호된 앱 폴더 안에.
- **다음 실행 때 폴더를 다시 열어도 된다는 macOS의 허가.** 저장되는 것은 폴더 경로이며
  파일 내용이 아닙니다. 그래야 앱이 실행할 때마다 다시 묻지 않아도 됩니다.
- **sCollectPlay에서는 추가로:** 최근에 쓴 폴더, XML 파일, 라이브러리의 목록, 직접 만든
  재생목록, 정렬과 열 브라우저의 상태 — 이것들도 보호된 앱 폴더 안에.

앱을 삭제하면 이 모든 것이 함께 제거됩니다.

## 의문이 생길 수 있는 두 가지 권한

**네트워크 접근.** 앱이 이 권한을 요청하는 까닭은, 이것이 없으면 macOS가 내장 도움말
창을 비어 있는 채로 보여 주기 때문입니다. 도움말을 그리는 것은 시스템 구성 요소이고,
그 구성 요소가 이 권한을 필요로 합니다. 프로그램 자신 안의 파일만 불러오는 경우에도
마찬가지입니다. 앱이 스스로 인터넷 주소를 호출하는 일은 **없으며**, 무언가를
내려받지도, 보고하지도 않습니다.

네트워크 드라이브(SMB, NFS)의 폴더에는 Mac의 파일 시스템을 통해 닿습니다. 앱
자신의 연결을 쓰는 것이 아닙니다.

**Apple Music 제어.** 선택한 항목을 재생목록으로 Apple Music에 보낼 때, 앱은 만들어진
재생목록으로 Apple Music을 열고, 원하면 그곳에 이미 있는 같은 이름의 재생목록을
대신합니다. 그러기 위해 macOS가 동의를 요구하며, 처음 한 번 묻습니다. 다른 프로그램을
앱이 제어하지는 않습니다.

## 사용자의 파일

앱은 태그를 쓰지 않으며 파일의 메타데이터를 바꾸지 않습니다.

sCollect 라이브러리를 열면 앱은 사용자의 별점과 재생 기록(날짜와 시간 포함)을 그 라이브러리 폴더의 `rueckmeldungen.json` 파일에 저장하여 sCollect가 가져갈 수 있게 합니다. 라이브러리 자체와 미디어 파일은 바꾸지 않으며, 이 내용은 사용자의 컴퓨터 밖으로 나가지 않습니다.

파일을 명시적으로 삭제할 때만 앱은 그 파일을 macOS 휴지통으로 옮기고 목록에서
뺍니다. 그 파일이 sCollect 라이브러리에 속해 있으면 그 카탈로그도 그에 맞게
고쳐집니다. 휴지통이 없는 드라이브에서는 파일을 영구히 삭제할지 앱이 먼저 묻습니다.

## Windows에서

위의 내용은 Mac에 관한 것입니다. Windows에서 sCollectPlay와 sCollectPlay Lite는 다음 항목을 앱의 데이터
폴더(`%LOCALAPPDATA%\Packages\<패키지>\LocalState` 및 `Settings`)에만 로컬로 저장합니다.

- **설정과 창 위치.**
- **마지막으로 선택한 소스** — 스캔한 폴더, iTunes XML 파일 또는 sCollect 라이브러리 — 와 마지막 스캔 결과.
- **라이브러리의 Mac 폴더와 PC 폴더의 대응 관계**(폴더 경로만).
- **sCollectPlay에서는 추가로:** 직접 만든 재생목록, 최근에 쓴 폴더, XML 파일, 라이브러리의 목록, 정렬과 열
  브라우저의 상태.
- **오류 로그**(`fehler.log`). 사용자의 PC 밖으로 나가지 않습니다.

이 모든 것은 앱을 제거하면 삭제됩니다.

앱은 사용자가 선택한 위치의 미디어 파일과 XML 파일만 읽습니다. sCollect 라이브러리는 읽기만 합니다(‘사용자의 파일’에서 설명한 `rueckmeldungen.json` 파일은 예외입니다). 앱은
자체적으로 네트워크에 연결하지 않으며, 분석 서비스와 광고도 없습니다. Windows가 직접 재생하지 못하는 파일은 해당
파일 형식의 기본 앱에 넘겨지며, 그 앱은 사용자가 Windows에서 정합니다.

sCollectPlay에서 재생목록을 VLC나 기기용으로 내보내면, 앱은 그 파일을 사용자가 선택한 폴더에 복사합니다.


스캔한 폴더나 iTunes XML의 미디어 파일을 명시적으로 삭제할 때만 앱은 그 파일을 Windows 휴지통으로 옮깁니다.
네트워크처럼 휴지통이 없는 드라이브에서는 확인을 거친 뒤 영구히 삭제됩니다. 이때 sCollect 라이브러리는
변경되지 않습니다.

## Microsoft Store

Windows에서는 구입(sCollectPlay), 다운로드, 업데이트가 Microsoft Store를 통해 이루어지며, 여기에는 Microsoft
개인정보처리방침이 적용됩니다. sCollectPlay Lite는 무료이며 정식 버전을 소개합니다.

## 제3자 제공 없음, 분석 없음

광고도, 분석 서비스도, 제3자에게 보내는 충돌 보고도, 계정도 없습니다.
